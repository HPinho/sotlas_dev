# Sotlas exceptions and timer interrupts

This kernel installs its interrupt table, handles breakpoints and a recoverable
protection exception, then receives hardware timer ticks while running floating
point code. The dispatcher and timer runtime are written in Sotlas; entry and
return machine code is generated by the owned image emitter.

From the repository root on Linux x86-64 or WSL, using a native Linux compiler
rebuilt from the current sources:

```sh
bash scripts/build_kernel.sh /path/to/sotlas-native build/my-irq-kernel --run --interrupts
```

Use a fresh output directory. The script requires QEMU x86-64 and `timeout` for
`--run`. To rebuild the compiler first using an existing native seed:

```sh
bash scripts/build_native.sh /path/to/native-seed build/my-compiler
bash scripts/build_kernel.sh build/my-compiler/sotlas-native build/my-irq-kernel --run --interrupts
```

No Python, C compiler, assembler or external linker is needed in these paths
after obtaining the seed. Success requires QEMU exit 85 and:

```text
SOTLAS: breakpoint and error frame OK
SOTLAS: timer and SSE preservation OK
```

The example deliberately triggers a #GP by loading selector 24. Its handler
checks the error code and instruction before advancing the saved RIP; copying
that recovery policy to arbitrary faults would be incorrect. Read the
[frame, runtime and target contract](../../docs/native_kernel_interrupts.md)
before changing the dispatcher.
